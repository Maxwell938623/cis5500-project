# **Overview**

This document contains 10 SQL queries for the MTA Fare Evasion analysis project. Queries marked [COMPLEX] satisfy the rubric requirement of drawing on multiple tables via joins, CTEs, subqueries, window functions, or multi-step aggregations. Queries 6–10 are the designated complex queries; Queries 7, 8, and 10 are the best candidates for the non-trivial runtime (>15s before optimization) requirement given the scale of the ridership table (~11M rows).

# **SQL Queries**

## **Query 1: Top 10 Busiest Stations by Total Ridership (2020–2024)**

**Description**

Aggregates total ridership across all years and quarters per station and returns the ten stations with the highest foot traffic. Provides baseline context for the Station Safety Index page — high-ridership stations should be expected to have proportionally higher enforcement.

**SQL**

SELECT sm.station_complex, sm.borough,

       SUM(r.ridership) AS total_ridership

FROM ridership r

JOIN station_meta sm

  ON r.station_complex_id = sm.station_complex_id

GROUP BY sm.station_complex, sm.borough

ORDER BY total_ridership DESC

LIMIT 10;

## **Query 2: Quarterly System-Wide Fare Evasion Rate Over Time**

**Description**

Retrieves the full historical time series of estimated fare evasion percentages and their margins of error in chronological order. This data populates the Financial Impact Analysis page's historical trend chart.

**SQL**

SELECT year, quarter,

       ROUND(fare_evasion * 100, 2)    AS evasion_pct,

       ROUND(margin_of_error * 100, 2) AS margin_of_error_pct

FROM fairevasion

WHERE fare_evasion IS NOT NULL

ORDER BY year ASC, quarter ASC;

## **Query 3: Total Arrests by Charge Severity and Year**

**Description**

Counts NYPD arrests broken down by felony/misdemeanor/violation (LAW_CAT_CD) and year. Used on the Borough-Level Equity page to show whether enforcement intensity has shifted toward more serious charges over time.

**SQL**

SELECT year, LAW_CAT_CD, COUNT(*) AS arrest_count

FROM arrests

GROUP BY year, LAW_CAT_CD

ORDER BY year, arrest_count DESC;

## **Query 4: Demographic Breakdown of Arrests by Borough**

**Description**

Counts arrests grouped by borough, age group, and race to surface demographic patterns in fare evasion enforcement. Supports the Borough-Level Equity Comparison page's equity analysis section.

**SQL**

SELECT sm.borough, a.AGE_GROUP, a.PERP_RACE,

       COUNT(*) AS arrest_count

FROM arrests a

JOIN station_meta sm

  ON a.station_complex_id = sm.station_complex_id

WHERE sm.borough IS NOT NULL

GROUP BY sm.borough, a.AGE_GROUP, a.PERP_RACE

ORDER BY sm.borough, arrest_count DESC;

## **Query 5: ADA-Accessible Stations per Borough**

**Description**

Counts fully ADA-accessible stations (ADA = 1) grouped by borough using the stationcoords table. Provides supplementary accessibility context for the Borough-Level Equity page.

**SQL**

SELECT sc.borough, COUNT(*) AS accessible_stations

FROM stationcoords sc

WHERE sc.ADA = 1

GROUP BY sc.borough

ORDER BY accessible_stations DESC;

## **Query 6: Estimated Revenue Lost to Fare Evasion per Quarter [COMPLEX]**

**Description**

Joins quarterly ridership totals with system-wide fare evasion rates to estimate how many rides were evaded and the resulting revenue loss, assuming a $2.90 base fare. This is the core formula powering the Financial Impact Analysis dashboard.

**SQL**

SELECT

    r.year,

    r.quarter,

    SUM(r.ridership)                                                     AS total_paid_rides,

    fe.fare_evasion                                                       AS evasion_rate,

    ROUND(SUM(r.ridership) / NULLIF(1 - fe.fare_evasion, 0))             AS est_total_boardings,

    ROUND(SUM(r.ridership) / NULLIF(1 - fe.fare_evasion, 0)

          * fe.fare_evasion)                                              AS est_evaded_rides,

    ROUND(SUM(r.ridership) / NULLIF(1 - fe.fare_evasion, 0)

          * fe.fare_evasion * 2.90, 2)                                   AS est_revenue_lost_usd

FROM ridership r

JOIN fairevasion fe

  ON r.year = fe.year AND r.quarter = fe.quarter

WHERE fe.fare_evasion IS NOT NULL

GROUP BY r.year, r.quarter, fe.fare_evasion

ORDER BY r.year, r.quarter;

## **Query 7: Station-Level Arrest Intensity vs. Ridership [COMPLEX]**

**Description**

Joins arrest counts with total ridership per station to produce an arrests-per-100k-riders metric. Stations at the extremes — over-policed relative to traffic vs. under-policed — are surfaced for the Station Safety Index page.

**SQL**

WITH station_arrests AS (

    SELECT station_complex_id, year, COUNT(*) AS total_arrests

    FROM arrests

    GROUP BY station_complex_id, year

),

station_ridership AS (

    SELECT station_complex_id, year, SUM(ridership) AS total_ridership

    FROM ridership

    GROUP BY station_complex_id, year

)

SELECT

    sm.station_complex,

    sm.borough,

    sr.year,

    sr.total_ridership,

    COALESCE(sa.total_arrests, 0)                                         AS total_arrests,

    ROUND(100000.0 * COALESCE(sa.total_arrests, 0)

          / NULLIF(sr.total_ridership, 0), 2)                            AS arrests_per_100k_riders

FROM station_ridership sr

JOIN station_meta sm ON sr.station_complex_id = sm.station_complex_id

LEFT JOIN station_arrests sa

    ON sr.station_complex_id = sa.station_complex_id

    AND sr.year = sa.year

ORDER BY arrests_per_100k_riders DESC;

## **Query 8: Borough Enforcement Disparity — Arrests vs. Estimated Evasion Volume [COMPLEX]**

**Description**

Computes per-borough arrest counts alongside estimated evasion volume derived from ridership and system-wide evasion rates. The ratio of actual arrests to estimated evaders is the primary equity metric on the Borough-Level Equity Comparison page — a high ratio indicates heavier policing relative to the underlying problem.

**SQL**

WITH borough_ridership AS (

    SELECT sm.borough, r.year, SUM(r.ridership) AS paid_rides

    FROM ridership r

    JOIN station_meta sm ON r.station_complex_id = sm.station_complex_id

    WHERE sm.borough IS NOT NULL

    GROUP BY sm.borough, r.year

),

annual_evasion AS (

    SELECT year, AVG(fare_evasion) AS avg_evasion_rate

    FROM fairevasion

    WHERE fare_evasion IS NOT NULL

    GROUP BY year

),

borough_est_evasion AS (

    SELECT br.borough, br.year, br.paid_rides, ae.avg_evasion_rate,

           ROUND(br.paid_rides / NULLIF(1 - ae.avg_evasion_rate, 0)

                 * ae.avg_evasion_rate)   AS est_evaded_rides

    FROM borough_ridership br

    JOIN annual_evasion ae ON br.year = ae.year

),

borough_arrests AS (

    SELECT sm.borough, a.year, COUNT(*) AS total_arrests

    FROM arrests a

    JOIN station_meta sm ON a.station_complex_id = sm.station_complex_id

    WHERE sm.borough IS NOT NULL

    GROUP BY sm.borough, a.year

)

SELECT

    be.borough,

    be.year,

    be.est_evaded_rides,

    COALESCE(ba.total_arrests, 0)                                         AS total_arrests,

    ROUND(100.0 * COALESCE(ba.total_arrests, 0)

          / NULLIF(be.est_evaded_rides, 0), 4)                           AS arrest_to_evasion_ratio

FROM borough_est_evasion be

LEFT JOIN borough_arrests ba

    ON be.borough = ba.borough AND be.year = ba.year

ORDER BY be.year DESC, arrest_to_evasion_ratio DESC;

## **Query 9: Annual Ridership Recovery vs. Arrest Rate Trends [COMPLEX]**

**Description**

Uses window functions to compute year-over-year percentage changes in both total ridership and total arrests. A divergence — e.g. ridership recovering while arrests spike — is analytically notable and feeds the Historical Time-Series Trend Analysis feature.

**SQL**

WITH annual_ridership AS (

    SELECT year, SUM(ridership) AS total_ridership

    FROM ridership

    GROUP BY year

),

annual_arrests AS (

    SELECT year, COUNT(*) AS total_arrests

    FROM arrests

    GROUP BY year

),

combined AS (

    SELECT ar.year, ar.total_ridership,

           COALESCE(aa.total_arrests, 0) AS total_arrests

    FROM annual_ridership ar

    LEFT JOIN annual_arrests aa ON ar.year = aa.year

),

with_lag AS (

    SELECT year, total_ridership, total_arrests,

           LAG(total_ridership) OVER (ORDER BY year) AS prev_ridership,

           LAG(total_arrests)   OVER (ORDER BY year) AS prev_arrests

    FROM combined

)

SELECT

    year, total_ridership, total_arrests,

    ROUND(100.0 * (total_ridership - prev_ridership)

          / NULLIF(prev_ridership, 0), 2) AS yoy_ridership_change_pct,

    ROUND(100.0 * (total_arrests - prev_arrests)

          / NULLIF(prev_arrests, 0), 2)   AS yoy_arrest_change_pct

FROM with_lag

ORDER BY year;

## **Query 10: Top Non-CBD Stations by Ridership with Arrest Counts per Borough [COMPLEX]**

**Description**

Joins ridership, station coordinates, and arrest data to identify the top 5 non-CBD stations per borough by total ridership alongside their arrest totals. Powers the Geospatial Heatmap's ridership layer and tests whether NYPD presence is skewed toward commercial areas (CBD) vs. high-traffic outer-borough stations.

**SQL**

WITH station_volume AS (

    SELECT r.station_complex_id, sm.station_complex, sm.borough,

           SUM(r.ridership) AS total_ridership

    FROM ridership r

    JOIN station_meta sm ON r.station_complex_id = sm.station_complex_id

    WHERE sm.borough IS NOT NULL

    GROUP BY r.station_complex_id, sm.station_complex, sm.borough

),

station_arrests AS (

    SELECT station_complex_id, COUNT(*) AS total_arrests

    FROM arrests

    GROUP BY station_complex_id

),

ranked AS (

    SELECT

        sv.station_complex, sv.borough, sv.total_ridership,

        COALESCE(sa.total_arrests, 0)                        AS total_arrests,

        sc.daytime_routes                                     AS lines,

        sc.latitude, sc.longitude,

        RANK() OVER (

            PARTITION BY sv.borough

            ORDER BY sv.total_ridership DESC

        )                                                     AS borough_rank

    FROM station_volume sv

    JOIN stationcoords sc

        ON sv.station_complex_id::TEXT = sc.complex_id::TEXT

    LEFT JOIN station_arrests sa

        ON sv.station_complex_id = sa.station_complex_id

    WHERE sc.CBD = FALSE

)

SELECT station_complex, borough, lines, latitude, longitude,

       total_ridership, total_arrests, borough_rank

FROM ranked

WHERE borough_rank <= 5

ORDER BY borough, borough_rank;

# **Implementation Notes**

The following notes are relevant for grading and optimization:

- Indexes on station_complex_id and year across the ridership and arrests tables will yield the largest performance gains for Queries 7–10.

- The station_complex_id type must be consistent across tables. The ::TEXT cast in Query 10 handles the stationcoords mismatch; consider normalizing this at ingestion time.

- Queries 6 and 8 both use NULLIF(..., 0) to guard against division-by-zero when evasion rate approaches 1.0 or ridership is zero.

- Query 9's LAG window function requires at least two years of data to produce non-null YoY change values.

- Credentials for the hosted AWS RDS database are provided separately to the project mentor.
